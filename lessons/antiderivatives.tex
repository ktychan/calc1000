\begin{document} \section{Antiderivatives}
We set up terminology and notation for integration which is the idea of \enquote{undoing} differentiation.

\begin{definition} \label{def:antiderivative}
  If \(f(x)\) and \(F(x)\) are related by
  \[
    f(x) = F'(x) \text{ for every } x \text{ in the domain of } f(x),
  \]
  then we \emph{say} \(F(x)\) is \hlwarn{an} antiderivative of \(f(x)\).
\end{definition}

\faStar{} In symbols, to find an antiderivative of \(f(x)\) is to fill in the blank 
\[
  \frac{d}{dx}\bigg( \hspace{1in} \bigg) = f(x).
\]
The function in the blank that makes the equation true is \emph{an} antiderivative.

\begin{example}
  This example is meant to help you understand the concept of an antiderivative for \(f(x)\).

  \begin{enumerate}[wide]
    \item Is \(xe^{x^{2}}\) an antiderivative of \(e^{x^{2}}\)?

      \blanks*

    \item Is \(e^{x^{2}}\) an antiderivative of \(2xe^{x^{2}}\)?

      \blanks*

    \item Is \(e^{x^{2}} + (\text{constant})\) an antiderivative of \(2xe^{x^{2}}\)?

      \blanks*
  \end{enumerate}
\end{example}

The fact that antideritives are not unique is captured in the following definition.

\begin{definition} \label{def:indefinite-integral}
  The \emph{indefinite integral} of \(f\) is a single expression representing \hlwarn{all} antiderivatives of \(f(x)\) and is denoted by \(\int f(x) \;dx\). 

  If \(\frac{d}{dx}\hlsupp{F(x)} = \hlmain{f(x)}\), then
  \[
    \int \hlmain{f(x)} \;dx = \hlsupp{F(x)} \hlwarn{\;+\;C},
  \]

  To \emph{evaluate} an indefinite integral \(\int f(x) \;dx\) is to find \(F(x) + C\) where \(F'(x) = f(x)\).

  \textbook{Definition, page 487}
\end{definition}

Algebraic properties of integrals break up complex integrals into simple ones.

\begin{thm}
  \begin{align*}
    \int c f(x) \;dx
    &= c \int f(x) \;dx && \text{(constant multiple)}\\
    \int f(x) + g(x) \;dx
    &= \int f(x) \;dx + \int g(x) \;dx && \text{(sum)}\\
    \int f(x) - g(x) \;dx
    &= \int f(x) \;dx - \int g(x) \;dx && \text{(difference)}
  \end{align*}

  \textbook{Theorem~4.16, page 491}
\end{thm}

\begin{example}[Final exam, Fall 2025]
  Suppose \(f'(x) = \frac{\sin(x) - 1}{\cos^{2}(x)}\) and \(f(0) = 3\). 

  Which of the following statements is true?

  \begin{enumerate}[label=(\Alph*)]
    \item \(f(x) = -3\frac{\cos(x) + x}{\cos^{3}(x)}\)
    \item \(f(x) = 3\frac{\cos(x) + x}{\cos^{3}(x) \sin(x)}\)
    \item \(f(x) = \sec(x)\tan(x) - \sec^{2}(x) - 1\)
    \item \(f(x) = \sec(x) - \tan(x) - 3\)
    \item \(f(x) = \sec(x) - \tan(x) + 2\)
  \end{enumerate}
\end{example}
