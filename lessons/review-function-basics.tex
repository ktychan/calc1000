Sophisticated functions are built by iteratively combining basic functions (the ones on the previous page) using operations
\[
  f+g \hspace{0.75in}
  f-g \hspace{0.75in}
  f \cdot g \hspace{0.75in}
  f/g \hspace{0.75in}
  f \circ g \hspace{0.75in}
  f(x) = \begin{cases} \cdots \\ \cdots \\ \cdots \end{cases}
\]

\faStar{} The operation \(f \circ g\) is called \underline{\hspace{1.5in}} and is defined by \(f \circ g = f(g(x))\).

\hlmain{Change of variable} is the the \enquote{opposite} of function composition. It is used to break up a complicated expression into smaller subproblems.  

We demonstrate a basic problem-solving technique using a change of variable. More complicated examples will be discussed in later lessons.
\begin{example}
  Solve the equation \(e^{2x} + e^{x} - 6 = 0\).

  \blanks*
\end{example}

\faStar{} \hlattn{Pattern recognition} hint: If you see a \hlmain{composite} function, try a change of variable! We will see lots examples throughout the course. 

High schools rarely discuss change of variable as an overarching problem-solving strategy. You tend to know them as \enquote{special tricks} applicable in specific situations. It is worth see the bigger picture because it is used in many situations in this course, including but not limited to the following.
\begin{itemize}
  \item Calculating domains such as \(\frac{1}{\sqrt{x + 1} - 1}\).

  \item Solve an equation involving \emph{composition} functions such as 
    \[
      e^{2x} + e^{x} - 6 = 0, 
      \quad
      \sin^{2}(x) - 3\sin(x) + 2 = 0,
      \quad
      \text{ or } 
      \quad
      \sqrt{x^{2} + 1} - x = 1.
    \]

  \item Evaluate limits such as 
    \[
      \lim_{x \to \infty} \frac{e^{2x}}{e^{3x} + 1}, 
      \quad
      \lim_{x \to 0} \frac{\sin^{2}(x)}{x}
      \quad\text{ or }\quad
      \lim_{x \to 1} \frac{\sqrt[3]{x} - 1}{\sqrt{x} - 1}.
    \]

  \item The chain rule in differentiation is a change-of-variable technique.

  \item The \enquote{\(u\)-sub} in integration is a change-of-variable technique in integration.
\end{itemize}
