Sophisticated functions are built by iteratively combining basic functions (the ones above, trigs, exponentials and logarithms) using operations
\[
  f+g \hspace{0.75in}
  f-g \hspace{0.75in}
  f \cdot g \hspace{0.75in}
  f/g \hspace{0.75in}
  f \circ g \hspace{0.75in}
  f(x) = \begin{cases} \cdots \\ \cdots \\ \cdots \end{cases}
\]

\clearpage
\faStar{} The operation \(f \circ g\) is called \hlmain{composition} and is defined by 
  \[
    (f \circ g)(x) = f(g(x)).
  \]

\hlmain{Change of variable} is the \enquote{opposite} of function composition. It is used to break up a complicated expression into smaller and more manageable pieces.

We demonstrate a basic problem-solving technique using a change of variable. More complicated examples will be discussed in later lessons.
\begin{example}
  Solve the equation \(e^{2x} + e^{x} - 6 = 0\).

  \blanks*
\end{example}

\faStar{} \hlattn{Pattern recognition} hint: If you see a \hlmain{composite} function, try a change of variable! We will see lots of examples throughout the course.

You may or may not have been taught that change of variable is a one-off trick. It is worth seeing the bigger picture. Change of variable is used fairly often in \thiscourse{}.
\begin{itemize}
  \item Calculate domains for \emph{composite} functions like \(\frac{1}{\sqrt{x + 1} - 1}\).

  \item Solve an equation involving \emph{composite} functions such as
    \[
      e^{2x} + e^{x} - 6 = 0, 
      \quad
      \sin^{2}(x) - 3\sin(x) + 2 = 0,
      \quad
      \text{ or } 
      \quad
      \sqrt{x^{2} + 1} - x = 1.
    \]

  \item Evaluate limits such as 
    \[
      \lim_{x \to \infty} \frac{e^{2x}}{e^{3x} + 1},

      \quad\text{ or }\quad
      \lim_{x \to 1} \frac{\sqrt[3]{x} - 1}{\sqrt{x} - 1}.
    \]

  \item Differentiate a composite function using the chain rule.

  \item Integrate a function using \enquote{\(u\)-sub}.
\end{itemize}

We talked about the five common operations \(+, -, \times, \div, \circ\). Now we discuss piecewise functions.

The left-brace notation for a piecewise function \(f(x)\) prescribes expressions for \(f(x)\) on two or more \emph{non-intersecting} intervals called subdomains. Each line in the left-brace notation is the expression for \(f(x)\) on the specified subdomain.  The domain of \(f(x)\) is the union of all its subdomains.

We now review absolute values. The absolute value function is fundamentally a piecewise function.
\begin{equation} \label{eq:abs}
  |x| = 
  \begin{cases}
    x, &\text{if } x \ge 0, \\
    -x, &\text{if } x < 0.
  \end{cases}
\end{equation}

\faExclamationTriangle{} The identity \(|x| = \sqrt{x^{2}}\) is true, but it makes easy-to-miss details even harder to notice. You are advised to use Equation~\eqref{eq:abs}.

To write down the absolute value of a function as a piecewise function, please remember that the input \(x\) shows up in five different places in Equation~\eqref{eq:abs}. You have to replace \(x\) in five places with the expression inside the absolute value.
