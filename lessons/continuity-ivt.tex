What \underline{mathematical property} of the temperature function \(H(t)\) \emph{guides} you to think this way?

Can you tell \underline{exactly} when (down to seconds) the temperature reached \(8^{\circ}\)C?

The Intermediate Value Theorem (IVT) is the mathematical description of the pattern we see on this page.
\clearpage

\begin{thm}[Intermediate Value Theorem]
  Let \(f\) be a \underline{\hspace{1in}} function over a closed, bounded interval \([a,b]\). If \(z\) is any real number between \(f(a)\) and \(f(b)\), then \underline{\hspace{1in}} a number \(c\) in \([a,b]\) satisfying \(f(c) = z\).

  \textbook{Theorem 2.11 on page 188}
\end{thm}
\blanklines{5}

The Intermediate Value Theorem (IVT) is \hlmain{useful} when we wish to \underline{\hspace{2in}} and \underline{\hspace{4in}}.

\blanklines{3}

To apply IVT, we must successfully complete three tasks: 
\begin{enumerate}[wide, label=(IVT \arabic*)]
  \item Find, guess, or be given {a \emph{closed and bounded} interval \([a,b]\)}
  \item Verify that {\(f\) is continuous on \([a,b]\)}.
  \item Verify that {\(z\) is between \(f(a)\) and \(f(b)\)}.
\end{enumerate}
If we cannot complete one or more of these tasks, then IVT \hlwarn{does not tell us anything}.

\begin{example}
  Show the function \(f(t) = t^{5} - t^{2} + 1\) has a root between \(-1\) and \(1\). \updatenote{The two terms were swapped (was \(t^{2} - t^{5} + 1\)); as originally written, \(f(-1) = 3\) and \(f(1) = 1\) are both positive, so IVT does not give a root on \([-1,1]\).}
\end{example}

We now have a lot of tools under our belt.  The next exercise helps you identify situations to which IVT applies.
\begin{exercise}
  Show that there is at least one number \(x\) for which the equation \(\frac{1}{x - 1} = x^{2} - 5\) is true on the interval \([-5,0]\).

  Analysis: The phrase \enquote{\emph{there is at least one}} (or just \enquote{\emph{exists}}) is the sign that we should use IVT because the question \emph{does not} need us to find such an \(x\) explicitly. It is equivalent to a yes-no question: \enquote{Is it possible to find at least one solution to \(\frac{1}{x-1} = x^{2} - 5\)?}

  Hint: The two equations \(\frac{1}{x-1} = x^{2} - 5\) and \(\frac{1}{x-1} - x^{2} + 5 = 0\) have the same set of solutions.  Therefore, it is enough to show the latter has a solution on the specified interval. This little manipulation works for all questions involving IVT.  

  \blanklines{15}
\end{exercise}
