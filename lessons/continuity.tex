\begin{document} \section{Continuity}
Intuitively, a function is \hlmain{continuous} if we can trace its graph without lifting our pencil. On the other hand, a function is \hlsupp{discontinuous at an \(x\)-value \(a\)} if we have to lift the pencil at \(a\) while tracing the graph of the function.

To make the idea of \emph{continuity} computable, we need to mathematically describe \enquote{lifting the pencil}.

\begin{definition}[continuity] \label{def:continuity}
  A function \(f(x)\) is \hlmain{continuous at a number \(a\)} if 
  \[
    {\lim_{x \to a} f(x) = f(a).}
  \]
  
  If this equality is false for any reason, then we say \hlsupp{\(f(x)\) is discontinuous at \(a\)} or \hlsupp{\(f(x)\) has a discontinuity at \(a\)}.

  \textbook{Page 180}
\end{definition}

Definition~\ref{def:continuity} is the first serious definition in \thiscourse{}. In plain English, \(f(x)\) is continuous at a constant \(a\) when we can successfully complete all three tasks:

  \begin{enumerate}[label=(C\arabic*), itemsep={2ex}]
    \item Calculate \underline{\hspace{3in}}.
    \item Calculate \underline{\hspace{3in}}.
    \item Verify \underline{\hspace{3.23in}}.
  \end{enumerate}

  \begin{example} \label{eg:continuity-intro}
    Is \(f(x) = \sqrt{x}\) continuous at \(1\)? 

    \blanklines{10}
  \end{example}
\end{sidefigure}
\clearpage

Example~\ref{eg:continuity-intro} shows us how to determine continuity \hlattn{when we have unfamiliar functions}. Theorem~\ref{thm:continuity-for-basic-functions} says such a computation need not be repeated for basic functions. 

\begin{thm} \label{thm:continuity-for-basic-functions}
  Basic functions (polynomials, rational functions, trig, inverse trig, exponentials and logarithms) are continuous at every number in their domain.

  \textbook{Theorem~2.8 on page 183 and Theorem~2.10 on page 188}
\end{thm}

  Find all \(x\)-values at which \(f(x) = \begin{cases} \frac{x^{2}-1}{x+1}, &\text{if } x \ne -1\\[1ex]0, &\text{if } x = -1\end{cases}\) is discontinuous.

  \blanklines{20}
\end{example}
\clearpage

Recall, from Definition~\ref{def:continuity}, that if \(f\) is \emph{not} continuous at \(a\), we say
\begin{center}
  ``\(f\) is \hlmain{discontinuous} at \(a\)'' \quad or \quad ``\(f\) has a \hlmain{discontinuity} at \(a\).''
\end{center}

We name different types of discontinuities and describe how to find them mathematically. \faStar{} Note that all three involve calculating one-sided limits.

\begin{definition} \label{def:discontinuities}
  There are three types of discontinuity.

  \begin{itemize}[itemsep={3ex}]
    \item A \hlsupp{removable discontinuity at \(x = a\)} is characterized by \(\lim_{x \to a^{-}} f(x) = \lim_{x \to a^{+}}f(x)\), and \(f(a)\) is not the common value or \(f(a)\) is undefined.

      \begin{center}
        \includestandalone[page=3]{../standalones/plot-continuity}
      \end{center}

    \item A \hlsupp{jump discontinuity at \(x = a\)} is characterized by \(\lim_{x \to a^{-}} f(x) \ne \lim_{x \to a^{+}}f(x)\) and both exist as finite numbers. The value \(f(a)\) is irrelevant.

      \begin{center}
        \includestandalone[page=4]{../standalones/plot-continuity}
      \end{center}

    \item An \hlsupp{infinite discontinuity at \(x = a\)} is just another name for a vertical asymptote at \(x = a\). Remember Definition~\ref{def:vertical-asymptote} on page~\pageref{def:vertical-asymptote}.

      \begin{center}
        \includestandalone[page=7]{../standalones/plot-continuity}
      \end{center}
  \end{itemize}
  \vspace{3ex}
\end{definition}

\clearpage

\label{technique:classify-discontinuities}
To \hlmain{classify} a discontinuity is to determine if the discontinuity is removable, a jump or an infinite discontinuity. 

\begin{center}
  \includestandalone[page=12]{../standalones/mindmap-limits}
\end{center}

We learn the general decision-making process for classifying discontinuities. We'll do it without any computation first so you can see the idea.

\begin{example} \label{eg:discontinuity-classify-abstract}
  Suppose you know the following about a function \(f(x)\). Find all of its discontinuities. For each discontinuity, determine if it is removable, jump or infinite.

  \begin{multicols}{3}
    \begin{itemize}
      \item \(f\) is continuous over \((-\infty, -5)\).
      \item \(f\) is continuous over \((-5, 2)\).
      \item \(f\) is continuous over \((2, \infty)\).
        \columnbreak
      \item \(f(-5) = 1\)
      \item \(\lim_{x \to (-5)^{-}} f(x) = 1\).
      \item \(\lim_{x \to (-5)^{+}} f(x) = 1/2\).
        \columnbreak
      \item \(f(2) = 0\)
      \item \(\lim_{x \to (2)^{-}} f(x) = 0\).
      \item \(\lim_{x \to (2)^{+}} f(x) = -\infty\).
    \end{itemize}
  \end{multicols}

  {\footnotesize Pro-tip: Try sketching the given information.}
  
  \blanks*
\end{example}

Here is what we can do \hlattn{if we know} a given function is continuous. 

\begin{sidefigure}{\includestandalone[page=10]{../standalones/mindmap-limits}}
  \begin{enumerate}[wide, itemsep={2ex}]
    \item If you know \(f(x)\) is continuous at \(a\), then you can use direct substitution to evaluate \(\lim_{x \to a} f(x)\). 

      We learned this last week.

    \item If you know \(f(x)\) is continuous, then you can use a change-of-variable to evaluate limits. 

      We also learned this last week.

    \item Apply the Intermediate Value Theorem.  
    
      This one is new. We discuss it after this page.
  \end{enumerate}
\end{sidefigure}

\vspace{1in}

Continuity provides the theoretical support for Points 1 and 2 above. In particular, change of variable works because of Theorem~\ref{thm:limit-composite}.

\begin{thm} \label{thm:limit-composite}
  If \(f\) is continuous at \(b\) and \(\lim_{x \to a} g(x) = b\), then 
  \[
    {\color{main} \lim_{x \to a}} {\color{attn}f({\color{black}g(x)})} = {\color{attn}f \left( {\color{main} \lim_{x \to a}} {\color{black} g(x) }\right)}.
  \]

  \textbook{Theorem~2.9 (Composite Function Theorem) on page 187}
\end{thm}

\begin{exercise} \label{ex:continuity-and-cancellation}
  Find the mistake(s) in the following \emph{incorrect} reasoning about the continuity of \[f(x) = \frac{(3x-1)(x-2)}{(x-2)}.\]
  \bigskip

  \begin{quote}
    \itshape
    We cancel the common factor to get
    \[
      f(x) = \frac{(3x - 1)\cancel{(x - 2)}}{\cancel{(x-2)}} = 3x - 1.
    \]
    Because \(3x - 1\) is a polynomial, we can conclude \(f(x)\) is continuous at every number, including \(x=2\).
  \end{quote}

  \blanklines{15}
\end{exercise}
