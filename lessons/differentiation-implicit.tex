\begin{document} \section{Implicit differentiation}

Implicit differentiation is a procedure to find the derivative of a function \(y = f(x)\) where \(f(x)\) is unknown but defined implicitly by an equation. We progress from familiar contexts to more complicated ones. 

\begin{example}
  Let \hlattn{\(y = f(x)\) be an unknown function}. Evaluate \(\frac{d}{dx}\left(x^{2} - xf(x) + \left(f(x)\right)^{2}\right)\).

  \blanks{20}
\end{example}

\begin{example} \label{eg:implicit-differentiation-intro}
  Let \hlattn{\(y = f(x)\) be an unknown function}. Differentiate \(x^{2} - xy + y^{2}\) with respect to \(x\).

  \blanks*
\end{example}

We say that \(y\) \hlmain{implicitly defines a function of \(x\)} near a point \(P\) on the curve if, after we zoom in enough near that point, the curve passes the vertical line test. In other words, near the point \(P\), we let \hlattn{\(y = f(x)\) be an unknown function} just like the setup in Example~\ref{eg:implicit-differentiation-intro}.

Implicit differentiation is a procedure to find \hlmain{\(\tfrac{dy}{dx}\)} without isolating \(y\) as an expression of \(x\).

\begin{mdframed}[style=simple-compact]
  \textbf{The procedure} for applying implicit differentiation to \emph{an equation} involving \(x,y\).
  
  \begin{enumerate}
    \item Differentiate both sides of \emph{the given equation} with respect to \(x\)
      \[
        \frac{d}{dx}\big(\cdots \text{LHS} \cdots \big) = \frac{d}{dx}\big(\cdots \text{RHS}\cdots\big).
      \]
    \item Isolate for \(\tfrac{dy}{dx}\) as a single symbol to get
      \begin{equation} \label{eq:dy-dx-implicit}
        \frac{dy}{dx} = \underbrace{\bigg(\cdots \text{an expression in \(x\) and \(y\)} \cdots\bigg)}_{\parbox{3in}{\centering \footnotesize represents the slope of the tangent line\\to the curve at a point \((x,y)\)}}.
      \end{equation}
  \end{enumerate}

  \faStar{} The slope of the tangent line at a point \(P=(a,b)\) \hlwarn{on the curve} is calculated by substituting \(x=a\) and \(y=b\) into the right-hand side of Equation~\eqref{eq:dy-dx-implicit}. If the point \(Q\) is NOT on the curve, then the slope of the tangent line at \(Q\) is undefined.
\end{mdframed}

We can use implicit differentiation to find the derivative of the inverse of a function. 

\begin{mdframed}[style=simple-compact]
  \textbf{How to} use implicit differentiation to calculate \((f^{-1})'(x)\) for an invertible \(f(x)\).

  Using \hlattn{the equation} \(y = f^{-1}(x)\),
  finding \(\left(f^{-1}\right)'(x)\) means to find \(\tfrac{dy}{dx}\) or just \(y'\). 
  \[
    \underbrace{\hspace{1.25in}}_{\parbox{1.25in}{\scriptsize\centering what we\\want to differentiate}}
    \quad\longleftrightarrow\quad
    \underbrace{\hspace{1.75in}}_{\text{apply the theory from page~\pageref{def:inverse}}} 
    \quad\longleftrightarrow\quad \underbrace{\hspace{1.25in}}_{\parbox{1.25in}{\scriptsize\centering implicitly differentiate\\this instead}}
  \]
\end{mdframed}
\blanks{3}

Theorem~\ref{thm:lift} below packages the thinking process demonstrated in Example~\ref{eg:implicit-differentiation-inverse-as-a-function} and Exercise~\ref{ex:implicit-differentiation-inverse} into a single formula. 

However, please be warned that Theorem~\ref{thm:lift} is only useful for finding \(\left(f^{-1}\right)'(\text{constant})\), but not suitable if you need to find \((f^{-1}(x))'\) as an expression of \(x\). For example, it is EXTREMELY COMPLICATED to use the theorem to solve Part 1 of Example~\ref{eg:implicit-differentiation-inverse-as-a-function}. Notice that at no point during Example~\ref{eg:implicit-differentiation-inverse-as-a-function} and Exercise~\ref{ex:implicit-differentiation-inverse} did we calculate \(f^{-1}\) as an expression of \(x\) because it was very complicated. 

It is possible to use Theorem~\ref{thm:lift} to solve Part 2 of Example~\ref{eg:implicit-differentiation-inverse-as-a-function} because \(6\) is a constant. 

\begin{thm}[The Inverse Function Theorem] \label{thm:lift}
  Suppose a function \(f\) is differentiable and has an inverse \(f^{-1}(x)\).
  \[
    \left(f^{-1}\right)'(\text{constant}) = \frac{1}{f'(f^{-1}(\text{constant}))}.
  \]
  The derivative (as a number) does not exist if the denominator is \(0\).

  \textbook{Theorem 3.11 on page 300}
\end{thm}
