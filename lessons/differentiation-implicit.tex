\begin{document} \section{Implicit differentiation}
We learn the full picture of implicit differentiation in two steps. Step one is about the procedure. Step two is about the geometry.

\begin{mdframed}[style=simple-compact]
  \textbf{The procedure}. To apply implicit differentiation to an equation involving \(x,y\) to find \(\tfrac{dy}{dx}\), we assume \hlmain{\(y\) implicitly defines a function of \(x\)} and do the following.
  \begin{enumerate}
    \item Differentiate both sides of the equation with respect to \(x\).
    \item \hlmain{Isolate} for \(\tfrac{dy}{dx}\) by treating \(\tfrac{dy}{dx}\) as a single symbol.
  \end{enumerate}

  The resulting \(\tfrac{dy}{dx}\) is an expression in \(x\) and \(y\).
\end{mdframed}

\begin{example} \label{ex:implicit-circle}
  Use implicit differentiation to find \(\tfrac{dy}{dx}\) given \(x^{2} + y^{2} = 25\).

  \begin{enumerate}[wide]
    \item Differentiate both sides with respect to \(x\).  \hfill{}\hlmain{\footnotesize Thinking trick: Pretend \(y\) is some unknown \(g(x)\).}

      \blanklines{10}

    \item Isolate for \(\tfrac{dy}{dx}\) to get \(\tfrac{dy}{dx} = \left( \cdots \text{ no } \tfrac{dy}{dx} \text{ on the RHS } \cdots \right)\).

      \blanklines{5}
  \end{enumerate}
\end{example}

\begin{example} \label{ex:implicit-differentiation-inverse}
  Find \(\frac{dy}{dx}\) at the point \((6,1)\) given \(x = y^{3} + 2y + 3\).   \hfill{\footnotesize Plug in \(x = 6\) and \(y = 1\) \hlwarn{at the end}!}

  \blanklines{15}
\end{example}

\textbf{Implicit function}. If we ``zoomed in enough'' at a point on the curve defined by the equation, e.g. Example~\ref{ex:implicit-circle}, we would see a function. In such a case, \hlmain{\(y\) implicitly defines a function of \(x\)} because there are one or more possibilities for such an expression \(y = f(x)\).

\begin{mdframed}[style=simple-compact]
  \textbf{The geometry}.  If \((x,y)\) is a point on the curve defined by an equation and \(\tfrac{dy}{dx}\) is the result of implicit differentiation of the equation, then the number we get by \hlsupp{plugging the values of \(x\) and \(y\) into \(\tfrac{dy}{dx}\)} represents the \hlmain{slope of the tangent line passing through \((x,y)\)}. 

  Caution: The point \((x,y)\) must be on the curve.
\end{mdframed}

Implicit differentiation helps us find an expression as \(y\) for the derivative of the inverse of any invertible function \(f\) without having to calculate \(y = f^{-1}(x)\) as an expression of \(x\). To do so, we implicitly differentiate the equivalent equation \(x = f(y)\) and isolate for \(\tfrac{dy}{dx}\) (see page \pageref{ex:implicit-differentiation-inverse}).

\begin{example} \label{eg:implicit-differentiation-inverse-as-a-function}
  Find an expression for the derivative of the inverse of \(f(x) = x^{3} + 2x + 3\).  Take for granted that \(f(x)\) is invertible, i.e., it passes the horizontal line test.

  \blanklines{5}
\end{example}

\begin{example} \label{eg:implicit-differentiation-inverse-at-a-point}
  Find the derivative of the inverse of \(f(x) = x^{3} + 2x + 3\) at \(6\), i.e., find \((f^{-1})'(6)\).

  {\footnotesize Hint: An expression for \((f^{-1})'\) is calculated in Example~\ref{ex:implicit-differentiation-inverse-as-a-function}. How do we use the number \(6\)?}

{\footnotesize Theorem~\ref{thm:lift} below packages the thinking process demonstrated in Examples~\ref{ex:implicit-differentiation-inverse-at-a-point}, \ref{ex:implicit-differentiation-inverse-as-a-function} and \ref{ex:implicit-differentiation-inverse},  into a single formula.  However, please be warned that Theorem~\ref{thm:lift} is only useful for finding \(\left(f^{-1}\right)'(\text{constant})\), but not suitable if you need to find \((f^{-1}(x))'\) as an expression of \(x\). Notice that at no point during Examples~\ref{ex:implicit-differentiation-inverse-at-a-point}, \ref{ex:implicit-differentiation-inverse-as-a-function} and \ref{ex:implicit-differentiation-inverse} did we calculate \(f^{-1}\) as an expression of \(x\) because it was very complicated. Everything we calculated was an expression of \(y\).
\begin{thm}[The Inverse Function Theorem] \label{thm:lift}
  Suppose a function \(f\) is differentiable and has an inverse \(f^{-1}(x)\). 
  \[
    \left(f^{-1}\right)'(\text{constant}) = \frac{1}{f'(f^{-1}(\text{constant}))}.
  \]
  The derivative (as a number) does not exist if the denominator is \(0\).

  \textbook{Theorem 3.11 on page 300}
\end{thm}

\begin{exercise}
  Suppose \(f\) is an invertible function and let \(y = f^{-1}(x)\). Moreover, someone calculated (correctly) that \(\frac{dy}{dx} = \frac{1}{5y^{4} + 9y^{2} + 2}\), \(f'(x) = 5x^{4} + 9x^{2} + 2\) and
  \[
    \quad f(-7) = -17851, 
    \quad f(-1) = -7,
    \quad f(0)  = -1.
    \quad f(1) = 5, 
    \quad f(5) = 3509,
  \]
  Find \((f^{-1}(x))'(-1)\).

  \blanklines{5}
\end{exercise}

When performing implicit differentiation on complicated algebraic expressions, remember the little thinking trick: Pretend \(y\) is a function \(g(x)\) to apply differentiation rules \hlmain{in the correct order}.  Your final answer should still be expressed in \(x\)'s and \(y\)'s.
