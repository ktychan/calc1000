\begin{document} \section{Implicit differentiation}
We learn the full picture of implicit differentiation in two steps. Step one is about the procedure. Step two is about the geometry.

\begin{mdframed}[style=simple-compact]
  \textbf{The procedure}. To apply implicit differentiation to an equation involving \(x,y\) to find \(\tfrac{dy}{dx}\), we assume \hlmain{\(y\) implicitly defines a function of \(x\)} and do the following.
  \begin{enumerate}
    \item Differentiate both sides of the equation with respect to \(x\).
    \item \hlmain{Isolate} for \(\tfrac{dy}{dx}\) by treating \(\tfrac{dy}{dx}\) as a single symbol.
  \end{enumerate}

  The resulting \(\tfrac{dy}{dx}\) is an expression in \(x\) and \(y\).
\end{mdframed}

\begin{example} \label{ex:implicit-circle}
  Use implicit differentiation to find \(\tfrac{dy}{dx}\) given \(x^{2} + y^{2} = 25\).

  \begin{enumerate}[wide]
    \item Differentiate both sides with respect to \(x\).  \hfill{}\hlmain{\footnotesize Thinking trick: Pretend \(y\) is some unknown \(g(x)\).}

      \blanklines{10}

    \item Isolate for \(\tfrac{dy}{dx}\) to get \(\tfrac{dy}{dx} = \left( \cdots \text{ no } \tfrac{dy}{dx} \text{ on the RHS } \cdots \right)\).

      \blanklines{5}
  \end{enumerate}
\end{example}

\begin{exercise} \label{ex:implicit-differentiation-inverse}
  Find \(\frac{dy}{dx}\) given \(x = y^{3} + 2y + 3\).  

  \blanklines{15}
\end{exercise}

\textbf{Implicit function}. If we ``zoomed in enough'' at a point on the curve defined by the equation, e.g. Example~\ref{ex:implicit-circle}, we would see a function. In such a case, \hlmain{\(y\) implicitly defines a function of \(x\)} because there are one or more possibilities for such an expression \(y = f(x)\).

\begin{mdframed}[style=simple-compact]
  \textbf{The geometry}.  If \((x,y)\) is a point on the curve defined by an equation and \(\tfrac{dy}{dx}\) is the result of implicit differentiation of the equation, then the number we get by \hlsupp{plugging the values of \(x\) and \(y\) into \(\tfrac{dy}{dx}\)} represents the \hlmain{slope of the tangent line passing through \((x,y)\) (on the curve!)}. 

  Caution: The point \((x,y)\) must be on the curve.
\end{mdframed}

\begin{example}
  Find an equation of the line tangent to the curve \(x^{2} + y^{2} = 25\) at \((3,4)\).

\end{example}

Implicit differentiation help us to find the derivative of the inverse of a function \(f(x)\) without actually having to calculate \(f^{-1}(x)\).  We simplify \hlmain{use implicit differentiation to find \(\tfrac{dy}{dx}\) from the equivalent equation \(x = f(y)\)}.

\begin{example}
  Find the derivative of the inverse of \(f(x) = x^{3} + 2x + 3\).  Take for granted that \(f(x)\) is invertible, i.e., it passes the horizontal line test.

  \blanklines{5}
\end{example}

\begin{example} \label{ex:implicit-differentiation-inverse-at-a-point}
  Find the derivative of the inverse of \(f(x) = x^{3} + 2x + 3\) at \(6\), i.e., find \((f^{-1})'(6)\).

  \blanklines{25}
\end{example}


If you prefer to memorize a formula for evaluating the derivative of the inverse of a function at a number, then the inverse function theorem is your friend.  The theorem simply packages the thinking process demonstrated in Example~\ref{ex:implicit-differentiation-inverse-at-a-point} into a single formula.  It is fine for finding \(\left(f^{-1}\right)'(\text{constant})\) (probably faster if it's all you need), but \faExclamationTriangle{} sometimes impossible if you need to find the \emph{function} \((f^{-1}(x))'\).
\begin{thm}[The Inverse Function Theorem]
  Suppose a function \(f\) is differentiable and has an inverse \(f^{-1}(x)\).  For all constants satisfying \(f'(f^{-1}(\text{constant})) \ne 0\),
  \[
    \left(f^{-1}\right)'(\text{constant}) = \frac{1}{f'(f^{-1}(\text{constant}))}.
  \]

  \textbook{Theorem 3.11 on page 300}
\end{thm}

When performing implicit differentiation on complicated algebraic expressions, remember the little thinking trick: Pretend\footnote{Assuming \(y\) is implicitly a function means to pretend that \(y\) is some \(f(x)\).} \(y\) is a function \(f(x)\) to guide you apply differentiation rules \hlmain{in the correct order}.  Your final answer should still be expressed in \(x\) and \(y\).
