\begin{document} \section{The Net Change Theorem}
The Net Change Theorem provides the physical meaning of FTC part 2. \updatenote{Capitalized "Theorem" for consistency with the theorem's name elsewhere.}

\begin{thm}
  If \(F(x)\) measures some physical quantity, then 
  \[
    F(b) - F(a) = \int_{a}^{b} F'(x) \;dx.
  \]

  \textbook{Theorem: 5.6: Net Change Theorem on page 567}
\end{thm}

\blanklines{5}

For example, if \(s\) is the displacement of an object, and \(v\) measures its velocity, then the Net Change Theorem says 
\[
  s(b) - s(a) = \int_{a}^{b} v(t) \;dt.
\]

\blanklines{10}

\begin{example}
  If \(v(t) = -t^{2} + 100\) is the velocity of some particle, find the \hlwarn{net displacement} from time \(t = 0\) to \(t = 30\).

  \blanklines{15}
\end{example}
\clearpage

Let's change the question ever so slightly from \hlwarn{net} displacement to \hlwarn{total} distance. The Net Change Theorem still applies, but it requires a small adjustment. \updatenote{"total displacement" corrected to "total distance" -- displacement is already the net (signed) quantity given by \(\int v(t)\,dt\); the quantity that requires the extra adjustment (integrating \(|v(t)|\)) is called total distance.}
\begin{exercise}
  If \(v(t) = -t^{2} + 100\) is the velocity of some particle, find the \hlwarn{total distance} from time \(t = 0\) to \(t = 30\).

  \blanklines{40}
\end{exercise}
