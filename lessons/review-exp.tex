\begin{document} \section{Review of exponential functions and logarithms}
A function \(b^{x}\), where \(b\) is a constant so that \(b > 0\) and \(b \ne 1\), is called an \hlmain{exponential function with base \(b\)} and exponent \(x\). Within the context of our textbook, every exponential function \(b^{x}\) has an \hlsupp{inverse} called the \hlmain{logarithmic function with base \(b\)}, denoted by \(\log_{b}(x)\). \newline
{\scriptsize Some authors allow \(1^{x}\) to be an exponential function. However, \(1^{x}\) is a constant function and does not have an inverse.}

Let's quickly recall exponent rules. \(e^{a}e^{b} = \underline{\hspace{1in}}\) and \((e^{a})^{b} = \underline{\hspace{1in}}\) for any \(a,b\).
\blanklines{4}

The number \(e\) is called Euler's number and is defined as \(e = \lim_{x \to \infty} \left( 1 + \frac{1}{x} \right)^{x}\). We will discuss this limit in week 3.
\bigskip

\begin{definition} \label{def:exp-ln}
  The \emph{natural} exponential function is \(e^{x}\) and the \emph{natural} logarithm is \(\ln(x) = \log_{e}(x)\).  They are inverses of each other:
  \begin{equation} \label{eq:exp-log}
    e^{\ln(x)} = x \text{ for \(x > 0\)} \quad\text{and}\quad \ln(e^{x}) = x \text{ for all \(x\)}.
  \end{equation}
\end{definition}

\faStar{} The goal of this lesson is to consolidate our knowledge of exponential and exponential-like functions into Equation~\eqref{eq:exp-log} and the ``\hlmain{change base to \(e\)}'' trick
\begin{equation} \label{eq:exp-change-of-base}
  b = \underline{\hspace{1cm}} \quad\text{and}\quad \underbrace{b^{x} = \hspace{1.5in}}_{\text{\hlmain{change base to \(e\)}}}, \quad\text{ but need } b > 0 \text{ and } b \ne 1.
\end{equation}
\blanks{5}

\hlmain{Change base to \(e\)} is a universal method for dealing with all exponential or exponential-like functions. The typical example is \(x^{x}\).

The formulas in Equation~\eqref{eq:log-formulas}, where \(a\) and \(b\) are positive and \(b \ne 1\), can be deduced from Equation~\eqref{eq:exp-change-of-base} and can help solve problems \emph{quickly}.
\begin{equation} \label{eq:log-formulas}
  \log_{b}(a) = \frac{\ln(a)}{\ln(b)},
  \quad
  \ln(a^{x}) = x \ln(a),
  \quad
  \ln(ab) = \ln(a) + \ln(b),
  \quad
  \ln(a/b) = \ln(a) - \ln(b).
\end{equation}

\begin{exercise}[Summary of exponential and logarithm rules]
  First, remember the universal method, \hlmain{change base to \(e\)}, for dealing with exponential or exponential-like functions.
  \[
    \begin{array}{rclcrcl}
      b^{x} &=& \underline{\hspace{1in}} 
            &\hspace{1em} & 
      \log_{b}(x) &=& \underline{\hspace{1in}} \\[2ex]
    \end{array}
  \]

  Once everything is in base \(e\), use the following rules.
  \[
    \begin{array}{rclcrclcrcl}
       && & & 
      \ln(e) &=& \underline{\hspace{1in}} &\hspace{1em} & \\[2ex]
      e^{\ln(x)} &=& \underline{\hspace{1in}} 
                 &\hspace{1em} & 
      \ln(e^{x}) &=& \underline{\hspace{1in}} 
                 &\hspace{1em} & 
      \ln(b^{x}) &=& \underline{\hspace{1in}} 
      \\[2ex]
      e^{a} e^{b} &=& \underline{\hspace{1in}}
                  &\hspace{1em} & 
      \ln(ab) &=& \underline{\hspace{1in}} \\[2ex]
      \frac{e^{a}}{e^{b}} &=& \underline{\hspace{1in}}
                          &\hspace{1em} & 
      \ln(a/b) &=& \underline{\hspace{1in}} \\[2ex]
    \end{array}
  \]
\end{exercise}
