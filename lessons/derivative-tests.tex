\begin{thm} \label{thm:first-derivative-test}
  Suppose \(f(x)\) is a differentiable function and \(I\) is an interval in the domain of \(f\).

  \begin{enumerate}[label=(\alph*)]
    \item If \(f' > 0\) on \(I\), then \(f(x)\) is (strictly) increasing over \(I\).
    \item If \(f' < 0\) on \(I\), then \(f(x)\) is (strictly) decreasing over \(I\).
  \end{enumerate}
\end{thm}

There are two more tests for local extrema. The idea is that if \(f(x)\) has a local extremum at \(c\), then \((c,f(c))\) must be the ``peak or valley of a mountain.'' \updatenote{"extrema" corrected to "extremum" (singular, matching "a").}  We simply ``look left and right'' at the corresponding critical point.

\begin{thm}
  Suppose that \(f\) is a continuous function on an interval \(I\) containing a critical number \(c\). If \(f\) is differentiable on \(I\), except possibly at \(c\), then \(f(c)\) satisfies one of the following descriptions:
  \begin{enumerate}
    \item If \(f'\) \emph{changes} sign from positive when \(x < c\) to negative when \(x > c\), then \(f\) has a local maximum at \(c\).
    \item If \(f'\) \emph{changes} sign from negative when \(x < c\) to positive when \(x > c\), then \(f\) has a local minimum at \(c\).
    \item If \(f'\) has the same sign for \(x < c\) and \(x > c\), then \(f(c)\) is neither a local maximum nor a local minimum of \(f\).
  \end{enumerate}

  \textbook{Theorem~4.9 First Derivative Test on page 392}
\end{thm}

We can dig up more information about a function by considering concavity.
\begin{definition}
  Let \(f\) be a differentiable function on an \emph{open} interval \(I\).
  \begin{itemize}
    \item If \(f'\) is increasing on an interval \(I\), then we say \(f\) is \hlmain{concave up}.
    \item If \(f'\) is decreasing on an interval \(I\), then we say \(f\) is \hlmain{concave down}.
    \item If \(f\) is continuous at \(c\) and changes concavity at \(c\), then \((c,f(c))\) is an \hlmain{inflection point}. 
  \end{itemize}

  \textbook{Definition on page 395 and 397}
\end{definition}

\begin{thm} \label{thm:second-derivative-test}
  Let \(f\) be a function whose second derivative exists on an interval \(I\).
  \begin{itemize}
    \item If \(f'' > 0\) on an interval \(I\), then the graph of \(f\) is \hlmain{concave up} on \(I\).
    \item If \(f'' < 0\) on an interval \(I\), then the graph of \(f\) is \hlmain{concave down} on \(I\).
  \end{itemize}

  \textbook{Theorem 4.10 Test for Concavity on page 396}
\end{thm}

The second derivative test offers a very fast way to find local extrema. However, it is only applicable to functions with a second derivative and can be inconclusive.

\begin{thm}
  Suppose \(f'(c) = 0\) and \(f''\) is continuous near \(c\).
  \begin{itemize}
    \item If \(f''(c) > 0\) (meaning \(f\) is concave \underline{\phantom{down}} near \(c\)), then \(f\) has a \underline{\hspace{1in}}.
    \item If \(f''(c) < 0\) (meaning \(f\) is concave \underline{\phantom{down}} near \(c\)), then \(f\) has a \underline{\hspace{1in}}.
    \item[\faExclamationTriangle{}] If \(f''(c) = 0\) or \(f''(c)\) does not exist, then the second derivative test is \hlwarn{inconclusive} meaning that we need to explore other methods to determine if \(f\) has a local extremum at \(c\). \updatenote{"extrema" corrected to "extremum" (singular, matching "a").}
  \end{itemize}

  \textbook{Theorem~4.11 Second Derivative Test on page 400}
\end{thm}

\end{example}
