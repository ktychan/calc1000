\begin{document} \section{Derivatives and the shape of a graph}

Some functions can be fairly complicated. However, we can use derivatives figure out its rough shape and features (intercepts, asymptotes, extrema, concavity, etc.).

Visually, a function \(f\) is \hlmain{increasing} on an interval if the \(y\)-value \(f(x)\) increases as \(x\) increases from left to right across the interval. Similarly, \(f\) is \hlsupp{decreasing} on an interval if the \(y\)-value \(f\) decreases as \(x\) increases from left to right across the interval.

\begin{thm} \label{thm:increasing-decreasing}
  Suppose \(f(x)\) is a differentiable and \(I\) is an interval.

  \begin{enumerate}[label=(\alph*)]
    \item If \(f' > 0\) on \(I\), then \(f(x)\) is (strictly) increasing over \(I\).
    \item If \(f' < 0\) on \(I\), then \(f(x)\) is (strictly) decreasing over \(I\).
  \end{enumerate}

  \textbook{Theorem~4.8 (Corollary 3 of the Mean Value Theorem) on page 387}
\end{thm}

We can dig up more information about a function by considering concavity.
\begin{definition}
  Let \(f\) be a differentiable function on an \emph{open} interval \(I\).
  \begin{itemize}
    \item If \(f'\) is increasing on an interval \(I\), then we say \(f\) is \hlmain{concave up}.
    \item If \(f'\) is decreasing on an interval \(I\), then we say \(f\) is \hlsupp{concave down}.
    \item If \(f\) is continuous at \(c\) and changes concavity at \(c\), then \((c,f(c))\) is an \hlattn{inflection point}.
  \end{itemize}

  \textbook{Definition on page 395 and 397}
\end{definition}

\begin{thm} \label{thm:concavity-test}
  Let \(f\) be a function whose second derivative exists on an interval \(I\).
  \begin{itemize}
    \item If \(f'' > 0\) on an interval \(I\), then the graph of \(f\) is \hlmain{concave up} on \(I\).
    \item If \(f'' < 0\) on an interval \(I\), then the graph of \(f\) is \hlmain{concave down} on \(I\).
  \end{itemize}

  \textbook{Theorem 4.10 Test for Concavity on page 396}
\end{thm}

We did bits and pieces of graph sketching throughout the term. We now put everything together.  Follow these steps to sketch the graph of \(f(x)\).
\begin{enumerate}
  \item Sketch \(y\)-intercept.
  \item Sketch \(x\)-intercept if they are easy to find.
  \item Sketch discontinuities (jump, removable and infinite).
  \item Sketch horizontal asymptotes.
  \item Find intervals of increase and decrease, and local extrema.
  \item Find intervals of concavity and inflection points.
  \item Lastly, sketch the graph using all of the information above.
\end{enumerate}

  \begin{itemize}
    \item \(f\) is continuous at every \(x\) except \(x = 1\).
    \item \(f(0) = 0\) and \(f(-2) = 4\).
    \item \(\displaystyle\lim_{x \to -\infty} f(x) = -\infty\) and \(\displaystyle\lim_{x \to \infty} f(x) = 2\).
    \item \(\displaystyle\lim_{x \to 1^{-}} f(x) = -\infty\) and \(\displaystyle\lim_{x \to 1^{+}} f(x) = \infty\).
    \item \(f' > 0\) on \((-\infty, -2)\), and \(f' < 0\) on \((-2, 1)\) and on \((1, \infty)\).
    \item \(f'' > 0\) on \((-\infty, -4)\) and on \((1, \infty)\), and \(f'' < 0\) on \((-4, 1)\).
  \end{itemize}
