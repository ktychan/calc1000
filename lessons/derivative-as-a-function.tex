\begin{document} \section{Derivatives (as functions)}

\begin{definition}
  The \emph{derivative} of a \(f(x)\), denoted as \(f'(x)\), is a function defined by
  \begin{equation} \label{eq:derivative}
    f'(x) = {\lim_{h \to 0} \frac{f(x+h) - f(x)}{h}}
  \end{equation}
  The function \(f'(x)\) is defined wherever the limit in Equation~\eqref{eq:derivative} exists.

  \textbook{Page 232}
\end{definition}

\textbf{Terminologies}.
\begin{itemize}
  \item To differentiate \(f\) (with respect to \(x\)) means to calculate \(f'(x)\).
  \item ``\(f(x)\) is differentiable at \(a\)'' means \(f'(a)\) is a finite number. 
  \item ``\(f(x)\) is differentiable on \((a,b)\)'' means \(f(x)\) is differentiable at every number in the interval.
\end{itemize}

In general, calculating derivatives from the definition is a tedious process.  In practice, we use differentiation rules.  For example, to calculate the derivative of a polynomial, we apply the rule \((x^{n})' = n x^{n-1}\) to each term, leaving the coefficients alone.  We will study differentiation rules in the next section.

Lastly, we record a relatively intuitive theorem.  
\begin{thm} \label{thm:differentiability-implies-continuity}
  If \(f\) is \hlsupp{differentiable at \(a\)}, then \(f\) is \hlmain{continuous at \(a\)} and, consequently, \hlmain{\(f(a)\) must be defined}.

  \textbook{Theorem 3.1 on page 237}
\end{thm}

Think of \hlmain{continuity at \(a\)} and the \hlmain{existence of \(f(a)\)} as critical ingredients for \hlsupp{differentiability at \(a\)}.
% If differentiability at \(a\) is a PB&J, then continuity at \(a\) and \(f(a)\) are like PB and peanuts.

\medskip
Correct ways to use the theorem:

\begin{itemize}
  \item Use it directly.
  \item If \(f(x)\) is undefined at \(a\) or discontinuous at \(a\), then \(f\) is not differentiable at \(a\).
\end{itemize}

\medskip
Incorrect ways to use the theorem:

\begin{itemize}
  \item If a function is continuous, then it must be differentiable.
  \item If a function is not differentiable, then it must be discontinuous.
\end{itemize}
