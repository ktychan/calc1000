\begin{document} \section{Derivatives (as functions)}

When we allow the symbol \(a\) in the definition of the derivative to vary, we get a new function \(f'(x)\) called the \emph{derivative function} of \(f(x)\).

\begin{definition}
  The \emph{derivative} of a function \(f(x)\) is a function denoted as \(f'(x)\) or \(\frac{d}{dx} f(x)\) and defined by
  \begin{equation} \label{eq:derivative}
    f'(x) = {\lim_{h \to 0} \frac{f(x+h) - f(x)}{h}}.
  \end{equation}
  The function \(f'(x)\) is defined wherever the limit in Equation~\eqref{eq:derivative} is a finite number.

  \textbook{Page 232}
\end{definition}

In practice, we use differentiation rules to calculate most derivatives. If differentiation rules do not work, then we \hlsupp{resort} to the limit definition as demonstrated in Example~\ref{eg:derivative-absolute-value} and Exercise~\ref{ex:midterm-f2025-derivative-at-a-point} on pages~\pageref{eg:derivative-absolute-value} and \pageref{ex:midterm-f2025-derivative-at-a-point}.

\textbf{Terminology}.
\begin{itemize}
  \item To \hlmain{differentiate} \(f\) (with respect to \(x\)) means to calculate \(f'(x)\) using any method, typically, but not always, differentiation rules.
  \item \enquote{\(f(x)\)} is \hlmain{differentiable at \(a\)}'' means \(f'(a)\) is a finite number.
  \item \enquote{\(f(x)\)} is \hlmain{differentiable over \((a,b)\)}'' means \(f(x)\) is differentiable at every number in the interval.
\end{itemize}
\bigskip

\faStar{} Derivatives appear everywhere thanks to their interpretation.  If \(f(x)\) represents some quantity, then \hlmain{\(f'(x)\) represents the instantaneous rate of change for \(f(x)\)}.

The most common example (which is our introductory example of a falling balloon) is the relation between the position function \(s(t)\) of a moving object and its derivative \(s'(t)\).  Another word for the instantaneous rate of change of position is velocity (as a vector quantity).
