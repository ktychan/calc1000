\begin{document} \section{Derivatives (as functions)}

\begin{definition}
  The \emph{derivative} of a function \(f(x)\) is a function denoted as \(f'(x)\) or \(\frac{d}{dx} f(x)\) and defined by
  \begin{equation} \label{eq:derivative}
    f'(x) = {\lim_{h \to 0} \frac{f(x+h) - f(x)}{h}}.
  \end{equation}
  The function \(f'(x)\) is defined wherever the limit in Equation~\eqref{eq:derivative} exists.

  \textbook{Page 232}
\end{definition}

\textbf{Terminologies}.
\begin{itemize}
  \item To \hlmain{differentiate} \(f\) (with respect to \(x\)) means to calculate \(f'(x)\) using any method, typically but not always, differentiation rules.
  \item ``\(f(x)\) is \hlmain{differentiable at \(a\)}'' means \(f'(a)\) is a finite number. 
  \item ``\(f(x)\) is \hlmain{differentiable on \((a,b)\)}'' means \(f(x)\) is differentiable at every number in the interval.
\end{itemize}

  {\footnotesize If we were to calculate \(f'(x)\) using the limit definition, we would completely evaluate the limit, which is a routine exercise in limit calculation. Be aware that, within the context of such a limit, \(x\) is a \emph{constant}, and \(h\) is the variable.}

\end{example}

\begin{example}

\faStar{} Strategy! In general, calculating derivatives from the definition is a tedious process.  In practice, we use differentiation rules. \hlmain{If differentiation rules do not work, then try the limit definition.}

\faStar{} Derivatives appear everywhere thanks to its physical meaning.  If \(f(x)\) represents some  quantity, then \hlmain{\(f'(x)\) represents the rate of change for \(f(x)\)}.  The most common example is the relation between the position function \(s(t)\) of a moving object and its derivative \(s'(t)\).  Another word for the rate of change of position is velocity (as a vector quantity).

Lastly, we record a relatively intuitive theorem.  
\begin{thm} \label{thm:differentiability-implies-continuity}
  If \(f\) is \hlsupp{differentiable at \(a\)}, then \(f\) is \hlmain{continuous at \(a\)} and, consequently, \hlmain{\(f(a)\) must be defined}.

  \textbook{Theorem 3.1 on page 237}
\end{thm}

Think of the \hlmain{existence of \(f(a)\)} and \hlmain{continuity at \(a\)} and as necessary ingredients for \hlsupp{differentiability at \(a\)}.
% If differentiability at \(a\) is a PB&J, then continuity at \(a\) and \(f(a)\) are like PB and peanuts.

\medskip
Correct ways to use the theorem:

\begin{itemize}
  \item Use it directly.
  \item See Example~\ref{eg:find-all-blah-differentiability}.
  \item If \(f(x)\) is undefined at \(a\) or discontinuous at \(a\), then \(f\) is not differentiable at \(a\).
\end{itemize}

\medskip
Incorrect ways to use the theorem:

\begin{itemize}
  \item If a function is continuous, then it must be differentiable.
  \item If a function is not differentiable, then it must be discontinuous.
\end{itemize}
