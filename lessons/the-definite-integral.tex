\begin{document} \section{Definite integrals}

The symbol \hlmain{\(\int_{a}^{b} f(x) \;dx\)} is the notation for a \hlmain{definite integral}, which represents net area.  This is a major concept in calculus.

\hlattn{Net area} of simple functions can be extended to arbitrary functions so that we can actually compute net area.

\begin{definition} \label{def:definite-integral-net-area}
  Geometrically, the symbol \(\int_{a}^{b} f(x) \;dx\) represents the \hlattn{net area} of a function \(f(x)\) over an interval \([a,b]\):
  \[
    \int_{a}^{b} f(x) \;dx = \underbrace{\hlmain{\left(\parbox{1.75in}{\centering the area of all regions below \(y = f(x)\) and above \(y = 0\)}\right)} - \hlsupp{\left(\parbox{1.75in}{\centering the area of all regions below \(y = 0\) and above \(y = f(x)\)}\right)}}_{\text{only the portion over the interval \([a,b]\) counts}}.
  \]

  The symbol \(\int_{a}^{b} f(x) \;dx\) is called a definite integral, \(f(x)\) the integrand, \([a,b]\) the interval of integration, \(a\) the lower bound, and \(b\) the upper bound. Depending on the information given, it can be calculated using a combination of geometry and algebraic rules.

  \textbook{page 532}
\end{definition}

Here is a summary.
\begin{thm} \label{thm:definite-integrals-properties}
  The net area interpretation of \(\int_{a}^{b} f(x)\;dx\) gives us these properties.
  \begin{align}
    \int_{a}^{a} f(x) \;dx &=   \text{the net area of a line} = 0 \\[1ex]
    \int_{a}^{b} f(x) \;dx &= - \int_{b}^{a} f(x) \;dx 
                           &&\text{(flip/time reversal)} \label{eq:definite-integral-flip} \\[1ex]
    \int_{a}^{b} f(x) \;dx &=   \int_{a}^{c} f(x) \;dx + \int_{c}^{b} f(x) \;dx 
                           &&\text{(split/join)} \label{eq:definite-integral-split}
  \end{align}
  In Equation~\eqref{eq:definite-integral-split}, \(c\) can be \emph{any} number, even one outside \([a,b]\). In other words, we can \emph{split} a definite integral anywhere, even outside \([a,b]\). 

  \textbook{Equations (5.9), (5.10) and (5.14) on pages 537 and 538}
\end{thm}

Here is a summary of approximation techniques. We also introduce some notations.

\faStar{} To approximate \(\int_{a}^{b} f(x) \;dx\) using \(n\) equal-width rectangles, we use the following notation. \label{page:riemann-notation} 

\begin{enumerate}
  \item The interval \([a,b]\) is divided into \(n\) equal-width sub-intervals by points \(x_{0}, x_{1}, x_{2}, \dots, x_{n}\). 
  \item \(\Delta x\) is a single symbol and means \(\Delta x = \frac{b-a}{n}\), representing the width of each sub-interval.
  \item The \(i\)-th interval is \([x_{i-1}, x_{i}]\).
  \item \(x_{i}^{*}\) is a \hlmain{choice} inside the \(i\)-th sub-interval, at which we evaluate \(f(x_{i}^{*})\).

    \faExclamationTriangle{} The approximation method, if specified, decides how we make such a choice in each interval. See the next page for three methods that you should remember.

  \item The \(i\)-th rectangle has width \(\Delta x\) and height \(f(x_{i}^{*})\), so the approximation is 
    \begin{equation} \label{eq:riemann-sum-expanded}
    f(x_{1}^{*}) \Delta x + f(x_{2}^{*}) \Delta x + \dots + f(x_{n}^{*}) \Delta x.
  \end{equation}
\end{enumerate}

\subsection{Riemann sums and the definite integral} \label{subsec:defint-formal}

\begin{definition} \label{def:riemann-sum}
  The \hlmain{Riemann sum} for a function \(f(x)\) defined over an interval \([a,b]\) is an approximation of \(\int_{a}^{b} f(x) \;dx\) using \(n\) equal-width rectangles. 

  In other words, Equation~\eqref{eq:riemann-sum-expanded} is a Riemann sum which is typically expressed using the Sigma notation
  \begin{equation} \label{eq:riemann-sum}
    \sum_{{\color{main}i}=1}^{{\color{main}n}} f(x_{{\color{main}i}}^{*}) \; {\color{supp} \Delta x} 
  \end{equation}

  \faStar{} The limit definition of the definite integral is
  \begin{equation} \label{eq:area-under-the-curve}
    \int_{a}^{b} f(x) \;dx = \lim_{n \to \infty} \sum_{i=1}^{n} f(x_{i}^{*}) \; \Delta x,
  \end{equation}
  if the limit exists.

  Equation~\eqref{eq:area-under-the-curve} is always true if \(f\) is continuous over \([a,b]\), or if \(f(x)\) is bounded and has only finitely many discontinuities in \([a,b]\).

  \textbook{Equation~(5.8) on page 529}
\end{definition}

To \hlmain{simplify} or to \hlmain{evaluate} a summation written in Sigma notation means to perform the specified addition.  The formulas in Equation~\eqref{formula:summations} are useful for evaluating definite integrals from their limit definition, i.e., the first principle.
\begin{equation} \label{formula:summations}
  \sum_{i=1}^{n} i = {\color{main} \frac{n(n+1)}{2}}, \qquad \sum_{i=1}^{n} i^{2} = {\color{main}\frac{n(n+1)}{2}} \cdot \frac{2n+1}{3}, \qquad \sum_{i=1}^{n} i^{3} = {\color{main}\frac{n(n+1)}{2}} \cdot \frac{n(n+1)}{2}.
\end{equation}
