We reviewed how \(\arcsin(x)\) undoes \(\sin(x)\), and how \(\ln(x)\) undoes \(e^{x}\). The idea of \enquote{undoing} goes further. Intuitively, the inverse of a function \(f(x)\) is another function \(g(x)\) that undoes whatever \(f(x)\) does to its input.

% Use Uber fare as an example as an inverse.
\begin{definition}[inverse] \label{def:inverse}
  Given a function \(f\) whose domain is \(D\) and range is \(R\), its \hlmain{inverse function} (if it exists) is \hlsupp{the} function \(f^{-1}(x)\) such that
  \[
    f^{-1}(f(x)) = x \text{ for every \(x\) in \(D\)} \quad\text{and}\quad f(f^{-1}(x)) = x \text{ for every \(x\) in \(R\)}.
  \]

  Terminology: A \hlmain{one-to-one function} is a function that has an inverse.

  {\footnotesize \faExclamationTriangle{} \(f^{-1}(x)\) is NOT \(\tfrac{1}{f(x)}\). To express \(\tfrac{1}{f(x)}\) as a power, write \(f(x)^{-1}\) or \(\big( f(x) \big)^{-1}\).}

  \textbook{Page 78}
\end{definition}

The subtlety of \enquote{undoing} is that the inverse function \(f^{-1}\) must undo \hlmain{every single input} in the domain of \(f\).
