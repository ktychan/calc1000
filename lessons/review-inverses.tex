Intuitively, the inverse of a function \(f(x)\) is another function \(g(x)\) that undoes whatever \(f(x)\) does to its input. This intuition is not precise enough to be useful. Let's start with the definition.

\begin{definition}[inverse] \label{def:inverse}
  Given a function \(f\) whose domain is \(D\) and range is \(R\), its \hlmain{inverse function} (if it exists) is \hlsupp{the} function \(f^{-1}(x)\) such that
  \[
    f^{-1}(f(x)) = x \text{ for every \(x\) in \(D\)} \quad\text{and}\quad f(f^{-1}(x)) = x \text{ for every \(x\) in \(R\)}.
  \]

  Terminology: An \hlmain{one-to-one function} is a function that has an inverse.

  \textbook{Page 78}
\end{definition}

{\footnotesize \faExclamationTriangle{} \(f^{-1}(x)\) is NOT \(\tfrac{1}{f(x)}\). To write \(\tfrac{1}{f(x)}\) as a power, write \(\tfrac{1}{f(x)} = f(x)^{-1}\) or \(\tfrac{1}{f(x)} = \big( f(x) \big)^{-1}\).}

\clearpage

There are two types of typical calculations involving inverse. 
\begin{itemize}
  \item Given two functions \(f(x)\) and \(g(x)\), determine if they are inverses of each other.
  \item Given a function \(f(x)\) and its domain, find an expression for its inverses.
\end{itemize}

The first type of question requires us to understand the definition.

The second type of question is a common procedure. To find the inverse of a function \(y = f(x)\), we switch \(x\) and \(y\) and isolate for \(y\). If you prefer, you can also first isolate for \(x\) in \(y = f(x)\) and swap \(x\) and \(y\) last. However, be warned that switching \(x\) and \(y\) first is also used in other situations, such as implicit differentiation.
