\begin{document} \section{Review of inverse functions}
Intuitively, the inverse of a function \(f(x)\) is another function \(g(x)\) that undoes whatever \(f(x)\) does to its input. This intuition is not precise enough to be useful. Let's start with the definition.

\begin{definition}[inverse] \label{def:inverse}
  Given a function \(f\) whose domain is \(D\) and range is \(R\), its \hlmain{inverse function} (if it exists) is \hlsupp{the} function \(f^{-1}(x)\) such that
  \[
    f^{-1}(f(x)) = x \text{ on } D \quad\text{and}\quad f(f^{-1}(x)) = x \text{ on } R.
  \]

  Terminology: An \hlmain{one-to-one function} is a function that has an inverse.

  \textbook{Page 78}
\end{definition}

{\faExclamationTriangle{} \(f^{-1}(x)\) is NOT \(\tfrac{1}{f(x)}\). To write \(\tfrac{1}{f(x)}\) as a power, write \(\tfrac{1}{f(x)} = f(x)^{-1}\) or \(\tfrac{1}{f(x)} = \big( f(x) \big)^{-1}\).}
\bigskip

We go through inverse functions in three steps: (1) the concept, (2) the algebra and (3) some unusual tricks.
\clearpage

(1) The concept. What does the above symbols all mean?! What does an inverse function look like graphically? How do we evaluate inverse functions?

We use the Horizontal Line Test to determine whether a function has an inverse.

\begin{exercise}
  Are \(f(x) = (x+1)^{3} - 2\) and \(g(x) = (x+2)^{1/3} - 1\) inverses of each other?

  \blanklines{15}
\end{exercise}

(2) The algebra. How do we find an inverse function?

To find the inverse of a function \(y = f(x)\), we switch \(x\) and \(y\) and isolate for \(y\). If you prefer, you can also first isolate for \(x\) in \(y = f(x)\) and swap \(x\) and \(y\) last. However, be warned that the switching \(x\) and \(y\) first is also used in other situation, such as implicit differentiation.

\begin{example} \label{eg:find-inverse}
  Find the inverse of \(\frac{2x}{1 + x}\).

\end{example}
