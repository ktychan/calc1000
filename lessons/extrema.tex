\section{Maxima and minima}
Applied optimization, such as maximizing profit or minimizing risk, is a landmark application of calculus.  In this lesson, we study some basic techniques to find the largest and smallest values of a function over a domain.  

Visually speaking, an \emph{absolute extremum} of a function \(y = f(x)\) is the highest or the lowest \hlwarn{finite} \(y\)-value on its graph.  The \emph{absolute} in \emph{absolute extrema} means \emph{for certain}, not \emph{absolute value}.

The idea of absolute extrema is captured \emph{precisely} using inequalities.
\begin{definition}
  Let \(f(x)\) be defined over an interval \(I\), and let \(c\) be in \(I\). 
  We say
  \begin{itemize}
    \item \(f\) has an \emph{absolute maximum on \(I\) at \(c\)} if \(f(c) \ge f(\text{every number \hlwarn{in} } I)\).

    \item \(f\) has an \emph{absolute minimum on \(I\) at \(c\)} if \(f(c) \le f(\text{every number \hlwarn{in} } I)\).
  \end{itemize}
  
  We also say that an extremum \emph{occurs at \(x=c\)} to mean that \(f(c)\) is an extremum.
  
  The plural of extremum is extrema.

  \textbook{Definition on page 366, slightly reworded}
\end{definition}
\faExclamationTriangle{} In other words, the absolute minimum for \(f(x)\) \emph{does not exist} if the range of \(f\) does not include the bottom endpoint. Similarly, the absolute maximum for \(f(x)\) \emph{does not exist} if the range of \(f\) does not include the top endpoint.

\begin{definition}
  Let \(f\) be a function. We say that

  \begin{itemize}
    \item \(f\) has a \emph{local maximum at \(c\)} if \(f(c) \ge f(\text{every number \hlmain{near} \(c\)})\).
    \item \(f\) has a \emph{local minimum at \(c\)} if \(f(c) \le f(\text{every number \hlmain{near} \(c\)})\).
  \end{itemize}

  Moreover, following our textbook convention, we impose that 
  \begin{center}
    \hlwarn{local extrema CANNOT occur at endpoints of the domain}.
  \end{center}

  \textbook{Definition on page 368, slightly simplified}
\end{definition}

The sketch on the previous page suggests two observations for finding local extrema.

\begin{enumerate}
  \item Some local extrema \hlmain{have flat tangent lines}. We can find them by solving \(f'(c) = 0\) for \(c\), which we practised earlier in the term.

  \item Some local extrema \hlsupp{do not have tangent lines at all}. To make sure we find all possible local extrema, we also need to look for \(c\) at which \(f'(c)\) does not exist.
\end{enumerate}

\begin{definition} \label{def:critical-number}
  The term \emph{critical number} captures both observations.

  A \emph{critical number} \(c\) is an \(x\)-value in the domain of \(f(x)\), but \hlwarn{NOT an endpoint}, if
  \[
    {\color{main}\quad f'(c) = 0} \quad\text{or}\quad {\color{supp} f'(c) \text{ does not exist}}.
  \]
  
  If \emph{\(c\) is a critical number} of \(f(x)\), then \((c, f(c))\) is called a \emph{critical point}.

  \textbook{Definition on page 369}
\end{definition}

\begin{thm}[Extreme Value Theorem and the closed-interval method] \label{page:extrema-strategy} \label{thm:closed-interval-method}
  Suppose \(f(x)\) is continuous and defined over a closed and bounded interval \([a,b]\). 
  Then \emph{both absolute extrema of \(f(x)\) must exist} and can can only occur at \(x\)-values, call them \(c\), in exactly one of three ways.
  \begin{itemize}
    \item \hlmain{\(f'(c) = 0\)} (and \(c\) is not an endpoint by the textbook convention),
    \item \hlsupp{\(f'(c)\) does not exist} (and \(c\) is not an endpoint by the textbook convention), or
    \item \hlwarn{\(c = a\)} or \hlwarn{\(c = b\)} (the endpoints).
  \end{itemize}
  
  \textbook{Theorem 4.1 (Extreme Value Theorem) on page 367, rephrased as a method}
\end{thm}
