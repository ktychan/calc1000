\begin{document} Solving applied optimization problems is a landmark application of differential calculus.  
To optimize something means to find the largest/smallest, most/least, etc., of something. 

Optimization problems are not ``cookie-cutter problems'' but doable. Suggested problems in textbook sections 4.3, 4.5 and 4.7 offer excellent opportunities to improve our problem-solving skills. In particular, finding extrema is a subtask of solving applied optimization problems.

\section{Maxima and minima}

We use inequalities to precisely capture the idea of absolute extrema.
\begin{definition}
  Let \(f\) be a function defined over an interval \(I\), and let \(c\) be in \(I\). \updatenote{Added the missing "be".} We say
  \begin{itemize}[itemsep={1ex}]
    \item \(f\) has an \hlmain{absolute maximum on \(I\) at \(c\)} if \(f(c) \ge f(\text{every number in } I)\).

      % The absolute maximum, if exist, is the largest number \hlwarn{in} the range.

    \item \(f\) has an \hlmain{absolute minimum on \(I\) at \(c\)} if \(f(c) \le f(\text{every number in } I)\).

      % The absolute minimum, if exists, is the smallest number \hlwarn{in} the range.
  \end{itemize}
  \textbook{Definition on page 366, slightly reworded}
\end{definition}

It is not wrong to say that the absolute max/min of \(f(x)\) is the largest/smallest number \hlwarn{in} the range of \(f\). \updatenote{"mn" corrected to "min".} It is just \emph{not helpful} for calculations because finding the range of a function is usually not an easy process except for reasonably simple functions. 

An absolute extremum is an absolute maximum or an absolute minimum. The plural of maxim\hlmain{um} is maxim\hlsupp{a}, minim\hlmain{um} is minim\hlsupp{a}, and extrem\hlmain{um} is extrem\hlsupp{a}.  Some textbooks use \emph{global} instead of \emph{absolute}. For example, global maximum and absolute maximum are interchangeable.

A problem-solving strategy (not math-specific) is to break up a large problem into smaller ones.  If we want to find absolute extrema, we start by looking for extrema over smaller intervals.

\begin{definition}
  Let \(f\) be a function defined over an interval \(I\).

  \begin{itemize}[noitemsep]
    \item \(f\) has a \hlmain{local maximum at \(c\)} if \(f(c) \ge f(\text{every number near \(c\)})\).
    \item \(f\) has a \hlmain{local minimum at \(c\)} if \(f(c) \le f(\text{every number near \(c\)})\).
  \end{itemize}

  Moreover, we impose that \hlwarn{local extrema CANNOT occur at endpoints of \(I\)}.

  \textbook{Definition on page 368, slightly simplified}
\end{definition}

Critical numbers are \(x\)-values at which local extrema \hlmain{could occur}.   Example~\ref{ex:critical-numbers} and Exercise~\ref{ex:critical-number-is-candidate} warn us about the subtle relation between critical numbers and local extrema.

\begin{definition}
  A \hlmain{critical number} \(c\) is a constant in the domain of \(f(x)\), but \hlwarn{NOT an endpoint}, if 
  \[
    \text{either } \quad f'(c) = 0 \quad\text{or}\quad f'(c) \text{ does not exist}.
  \]
  If \hlmain{\(c\) is a critical number} of \(f(x)\), then \hlsupp{\((c, f(c))\)} is called a \hlsupp{critical point}.

  \textbook{Definition on page 369} {\footnotesize \faExclamationTriangle{} See a grading warning at the bottom of page~\pageref{warning:critical-number}.}
\end{definition}

\begin{mdframed}[style=simple-compact]
  A strategy for finding absolute extrema comes from Fermat's Theorem (read Theorem 4.2 on textbook page 369). 

  Absolute extrema for a function defined over an interval \hlwarn{can} only occur at \(x\)-values, call them \(c\), in exactly one of two ways:
  \begin{center}
    either \underline{\hspace{2.5in}} or \underline{\hspace{2.5in}}.
  \end{center}
\end{mdframed}

{\footnotesize An arbitrary function can approach an infinity or oscillate towards infinities, so one or both absolute extrema do not always exist. In general, we have to rule out the non-existence of absolute extrema or restrict the domain somehow before applying the above general strategy. \updatenote{Fixed a comma splice (added "so"), changed "absolute extremum" to "absolute extrema" to agree with "one or both" earlier in the sentence, and removed a stray "by" so "rule out \ldots{} or restrict \ldots{}" is parallel.}}

A theoretical result called the Extreme Value Theorem (read Theorem 4.1 on textbook page 367) says that \emph{both} absolute extrema for \hlmain{continuous} functions defined over a \hlmain{closed and bounded} interval \([a,b]\) always exist. 



\begin{example}

  \[
    f(x) = \frac{3}{2} x^{2/3} - x^{2}/2 \qquad\text{defined over } [-2,2].
  \]

  This is the function from Example~\ref{ex:critical-number-rational}. Note that \(\frac{3}{\sqrt[3]{2}}-2 \approx 0.381\).

  \blanklines{25}
\end{example}
