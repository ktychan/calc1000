\begin{document} \section{The substitution rule}

We have seen throughout the course that \hlmain{a change of variable} can \emph{transform} a complicated problem into a simpler one. The substitution rule performs such a change of variable in integration. It reverses the chain rule (in differentiation).

\begin{thm} \label{thm:substitution}
  {If {\color{main} \(u = g(x)\)} is differentiable and \(f\) is continuous on the range of \(g\), then}
  \begin{equation} \label{eq:sub-definite}
    \int_{a}^{b} f( {\color{main} g(x)} ) \, {\color{supp} g'(x) \;dx} = \int_{g(a)}^{g(b)} f({\color{main} u}) \;{\color{supp}du}.
  \end{equation}

  For indefinite integrals, there are no bounds to change:
  \begin{equation} \label{eq:sub-indefinite}
    \int f( {\color{main} g(x)} ) \, {\color{supp} g'(x) \;dx} = \int f({\color{main} u}) \;{\color{supp}du}.
  \end{equation}

  The \enquote{cheat} formula \(dx = \frac{du}{u'(x)}\) can help you perform the substitution step for \(dx\).

  \textbook{Theorem 5.7 on page 584 and Theorem 5.8 on page 589}
\end{thm}

\medskip
\begin{example}
  Evaluate \(\int_{1}^{2} x e^{x^{2}} \;dx\).

  \begin{enumerate}[wide]
    \item Choose \(u = \underline{\hspace{1in}}\) by looking for an inside function and calculate \(dx\) to prepare for the next step.

      \blanks{5}

    \item Perform the substitution according to Theorem~\ref{thm:substitution}. Every expression in \(x\) must be written in \(u\) at the end of this step. If we cannot do so, then the substitution is unsuccessful. 

      This is a definite integral, so the bounds must also be substituted according to Equation~\eqref{eq:sub-definite}.

      \blanks{10}

    \item Evaluate the new integral in \(u\).

      \blanks*
  \end{enumerate}
\end{example}

\textbf{Strategy} for choosing \(u\).\label{page:u-sub-strategy} \hlattn{Recognize} a \hlmain{pair} of functions (almost) related by differentiation and choose \(u\) to be the antiderivative.  An extra clue is that \(u\) could be an inside function of a composite function. Sometimes, there is more than one choice for \(u\) that works. Be brave and use trial and error to develop intuition!

\faExclamationTriangle{} The integration table on page~\pageref{sec:integration-formulas} \hlmain{guarantees correctness}. If something is not in the integration table, then you should manipulate it into one or more known integrals, using properties of integrals and/or substitution.

\begin{example} \label{ex:u-sub-1}
  Evaluate \(\int x^{2} \sqrt{1 + x^{3}} \;dx\).

  \begin{enumerate}[wide]
    \item Choose \(u = \underline{\hspace{1in}}\) by looking for an inside function and calculate \(dx\) to prepare for the next step.

      \blanks{10}

    \item Perform the substitution according to Theorem~\ref{thm:substitution}. Every expression in \(x\) must be written in \(u\) at the end of this step. If we cannot do so, then the substitution is unsuccessful. 

      \blanks{10}

    \item Evaluate the new integral in \(u\). We have an indefinite integral here, so the final result needs to be written in terms of \(x\).

      \blanks*
  \end{enumerate}
\end{example}
