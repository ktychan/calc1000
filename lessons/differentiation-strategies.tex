\begin{document} \section{Differentiation strategies}

\emph{Logarithmic differentiation} can \hlmain{quickly} differentiate complicated expressions involving exponentials, products and quotients. The process is exactly the same for both types of expressions. It works by combining implicit differentiation, Equation~\eqref{eq:derivative-of-ln(g(x))} below and properties of logarithms.
\begin{thm}
  If \(g'(x)\) exists, then the chain rule and \(\tfrac{d}{dx} \ln(x) = \tfrac{1}{x}\) imply
  \begin{equation} \label{eq:derivative-of-ln(g(x))}
    \frac{d}{dx} \ln( g(x) ) = \frac{g'(x)}{g(x)}.
  \end{equation}

  \textbook{Equation~(3.33) specialized to \(b = e\). See page 326.}
\end{thm}

\begin{example} \label{ex:log-diff-exponentials}
  Find \(\frac{dy}{dx}\) given \(2^{y^{2} + \ln(x)} = \frac{xy}{x + 1}\).

  \begin{enumerate}[wide, noitemsep, label=(Step~\arabic*).]
    \item Take \(\ln(\cdots{})\) on both sides and \emph{fully} \footnote{Removes the necessity to use the product or quotient rule so you can differentiate quickly!} simplify.

      \blanklines{5}

    \item Implicitly differentiate with respect to \(x\). Use Equation~\eqref{eq:derivative-of-ln(g(x))} when appropriate.

      \blanklines{20}

    \item Isolate for \(\frac{dy}{dx}\).

      \blanklines{5}
  \end{enumerate}
\end{example}
\clearpage

Logarithmic differentiation for (explicit) functions requires an extra step. Restore \(\tfrac{dy}{dx}\) as an expression of \(x\) in the final expression for \(\tfrac{dy}{dx}\). However, leave the symbol \(\tfrac{dy}{dx}\) as is.

\begin{exercise} \label{ex:log-diff}
  Differentiate \(y = \frac{\sin(2x)^{4/3}}{e^{x} \cos^{5}(x)}\).

  \begin{enumerate}[wide, noitemsep, label=(Step~\arabic*).]
    \item Take \(\ln(\cdots{})\) on both sides and \emph{fully}\footnote{Removes the necessity to use the product or quotient rule so you can differentiate quickly!} simplify.

      \blanklines{10}

    \item Implicitly differentiate with respect to \(x\). Use Equation~\eqref{eq:derivative-of-ln(g(x))} when appropriate.

      \blanklines{20}

    \item Isolate for \(\frac{dy}{dx}\).

      \blanklines{5}

    \item Replace \(y\) by the original expression \(f(x)\), so that \(\frac{dy}{dx}\) is restored as a function of \(x\).

      \blanklines{5}
  \end{enumerate}
\end{exercise}
\clearpage

After applying the chain rule \(\frac{dy}{dx} = \frac{dy}{d{\color{main}u}} \frac{d{\color{supp}u}}{dx}\), if calculating \(\frac{d{\color{supp}u}}{dx}\) requires differentiating another composite function, then treating it as a side computation is often a safe choice.  While this is not the fastest, it is conceptually clean.

\begin{exercise}
  Differentiate \(\sin(e^{\cos(x) + 5x})\).

  \blanklines{20}

  {\footnotesize The fast starting step: \(\frac{d}{dx} \sin(e^{\cos(x) + 5x}) = \left(\frac{d}{du} \sin(u) \right) \left(\frac{d}{dv} e^{v} \right) \left( \frac{d}{dx} \cos(x) + 5x \right)\) where \(u = e^{v}\) and \(v = \cos(x) + 5x\).}
\end{exercise}

\begin{exercise}
  Find all \(x\) in \([0, 2\pi]\) at which \(\frac{d}{dx} \sin(x)\) has a tangent line of slope \(1\). 

  \bigskip
  Legit or fishy?  We solve for \(x\) in the interval \([0,2\pi]\):
  \[
    \frac{d}{dx} \sin(x) = 1 \quad\longrightarrow\quad \cos(x) = 1 \quad\longrightarrow\quad x = 0.
  \]
  Therefore, \(\frac{d}{dx} \sin(x)\) has a tangent line of slope \(1\) at \(x = 0\).

  \blanklines{20}
\end{exercise}

\begin{exercise}
  Find \(x\) at which \(\arctan(x)\) has a vertical tangent line.

  Legit or fishy? Let \(y = \arctan(x)\). The question translates to solving for \(x\) given \(\frac{dx}{dy} = 0\).
  \[
    \frac{d}{dy} y = \frac{d}{dy} \arctan(x) 
    \quad\longrightarrow\quad
    1 = \frac{1}{1 + x^{2}}
  \]
  The equation is true at \(x = 0\). So \(\arctan(x)\) has a vertical tangent line at \(x = 1\).

  \blanklines{15}
\end{exercise}
\clearpage

\begin{exercise}[Midterm, Fall 2022] 
  Use implicit differentiation to find an equation to the tangent line of the curve \(\sin(x+y) = 2x - 2y\) at the point \((\pi, \pi)\).

  Legit or fishy? The tangent line is \(y = \frac{1}{3}(x - \pi) + \pi\) because
  \begin{align*}
    &&\frac{d}{dx} \sin(x + y) &= \frac{d}{dx}(2x - 2y) \\
    &\longrightarrow &\cos(x + y)\left(1 + \frac{dy}{dx}\right) &= 2 - 2 \frac{dy}{dx} \\
    &\longrightarrow &\cos(\pi + \pi)\left(1 + \frac{dy}{dx}\right) &= 2 - 2 \frac{dy}{dx} \\
    &\longrightarrow &\frac{dy}{dx} &= \frac{1}{3}.
  \end{align*}

  \blanklines{10}
\end{exercise}
